# Roadmap

This roadmap is informational and does not represent shipped APIs unless noted in release documentation.

## Near-term priorities

1. API reference expansion
   - method-level examples and edge-case behavior notes.
2. CLI ergonomics
   - non-interactive add/update flows and machine-readable output mode.
3. API server hardening
   - endpoint coverage tests and versioned API docs improvements.

## LLM integration direction (not shipped)

Potential future work:

- optional provider adapters,
- context assembly helpers on top of core graph retrieval,
- explicit token budgeting utilities.

Any such features will be released behind clearly documented, versioned package surfaces.
